# Deezer Music

**Deezer Music** is a modern, open-source Android music application designed to provide a powerful and fluid music listening experience.

Built with **100% Kotlin** and **Jetpack Compose**, Deezer Music combines music discovery, high-quality playback, synchronized lyrics, music recognition, offline listening, queue management, sleep timers, genre discovery, and real-time listening rooms into one experience.

> **LIVE THE MUSIC.**
